Data kepemilikan ditarik per bulan dan tidak ikut rantai harian. Tarik tiap awal bulan: KSEI dulu (posisi akhir bulan lalu, biasanya terbit beberapa hari setelah tutup bulan), lalu registri IDX dan LBRPE. Semua tombol di sini menjalankan fungsi yang sama dengan python -m website.ownership, dan yang sudah ada bulan ini dilewati, jadi aman dijalankan ulang. Hasilnya dipakai di Kepemilikan Saham.
KSEI · komposisi investor
—
Asing / ritel / institusi per emiten. Satu ZIP per bulan, selesai dalam belasan detik.
Registri IDX · pemegang saham bernama
—
Pemegang ≥5%, direksi, komisaris. Sejak Sep 2026 IDX menolak tarikan dari Python, jadi ditarik lewat browser kamu (lihat kartu di bawah). Tombol "Coba langsung" tetap ada kalau suatu saat dibuka lagi.
Tarik lewat browser
LBRPE · free float & jumlah SID
—
Satu PDF per emiten, dibaca server. Sama seperti registri, sejak Sep 2026 ditarik lewat browser kamu. Emiten tanpa laporan 4 bulan terakhir dihitung "kosong", bukan gagal.
Tarik lewat browser
Registri IDX lewat browser
  1. Berisi emiten yang belum punya registri bulan ini.
  2. Buka www.idx.co.id di Chrome/Edge biasa, tekan F12 → tab Console, tempel, Enter. (Pertama kali Chrome minta ketik allow pasting dulu.) Biarkan tabnya terbuka; ~30–40 menit untuk semua emiten, progresnya muncul di Console.
  3. Selesai, file registri_idx_<bulan>_<n>.json terunduh otomatis. Impor di sini:
Mau berhenti di tengah: ketik bdmBerhenti = true di Console, yang sudah terambil tetap tersimpan. Kalau IDX minta verifikasi ulang, skrip berhenti sendiri dan menyimpan hasilnya. Impor, lalu salin skrip baru: yang sudah diimpor otomatis dilewati.
LBRPE lewat browser
  1. Emiten yang belum punya laporan terbitan bulan ini.
  2. Di tab www.idx.co.id, F12 → Console, tempel, Enter, sama seperti registri. Jangan barengan dengan skrip registri, tunggu yang satu selesai dulu. Dua request per emiten (daftar pengumuman + PDF), jadi ~60–70 menit untuk semua. PDF yang tidak berubah sejak tarikan terakhir tidak diunduh ulang.
  3. Selesai, file lbrpe_idx_<bulan>_<n>.json (bisa puluhan MB) terunduh. Impor di sini; server membaca PDF-nya di latar, kemajuannya muncul di kotak Keluaran:
Berhenti di tengah: bdmBerhenti = true di Console. LBRPE bulan berjalan biasanya baru lengkap sekitar tanggal 10–15; sebelum itu sebagian emiten masih memakai laporan bulan lalu.
Pemantauan Khusus · jurnal maju
Bukan data kepemilikan, tapi jalurnya sama: pengumuman BEI "Efek Bersifat Ekuitas Dalam Pemantauan Khusus" untuk jurnal maju temuan 18 Okt 2026 (masuk papan karena kriteria fundamental = sinyal hindari). Tarik kira-kira seminggu sekali; kesehatan mengingatkan kalau lewat 14 hari.
  1. Mulai seminggu sebelum tarikan terakhir; yang sudah diimpor dilewati.
  2. Di tab www.idx.co.id, F12 → Console, tempel, Enter. Skrip memuat pdf.js dari cdnjs untuk membaca PDF pengumumannya; biasanya kurang dari satu menit.
  3. File pk_idx_<tanggal>_<n>.json terunduh. Impor di sini:
Per emiten
Sync sekarang = registri IDX + LBRPE langsung (maks. 10 kode, ditunggu sampai selesai). Pakai ini untuk emiten yang baru IPO atau baru saja keluar laporannya.
